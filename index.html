Crypto MM Journal

A personal Google Apps Script that keeps a trading journal for its owner's own bots.

Crypto MM Journal is a private, single-user tool. Trading bots running on the owner's computer send their paper-trading results to a Google Sheet that the owner owns. The script stores those results in the Sheet, builds a dashboard, and emails the owner a periodic summary report.

It is not a public service: it is used only by the person who created it, and nobody else can sign up for or use it.

What it accesses

  • Google Sheets: only the owner's own trading-journal spreadsheet, to store results and build the dashboard.
  • Gmail (send only): to send the summary report to the owner.
  • Script triggers: to run the scheduled report and weekly tuning.
